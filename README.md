# Joseph Okologo — Academic Portfolio

A responsive five-page academic portfolio and student planner built with HTML, CSS, and vanilla JavaScript.

## Pages
- `index.html` — homepage and welcome
- `about.html` — education, aspirations, skills, interests, roadmap table
- `projects.html` — three sample projects and multimedia audio element
- `planner.html` — add, complete, and delete tasks (saved with localStorage)
- `contact.html` — contact form validation (all fields required, email format, digits-only phone)

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Personalise before submission
1. Replace the initials graphic on the homepage with your photograph.
2. Review the education and biography text for accuracy.
3. Add your own project screenshots and repository URLs.
4. Optionally add an `intro.mp3` file beside `projects.html` for audio playback.
5. The contact form is a front-end demo and does not send data to a server.

## Publish with GitHub Pages
1. Create a GitHub repository named `academic-portfolio`.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After GitHub finishes publishing, copy the public Pages URL shown in that settings screen.

Use the repository URL and published GitHub Pages URL when submitting the assignment.
